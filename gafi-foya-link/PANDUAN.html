Masuk ke aplikasi

Buka tautan aplikasinya; tidak perlu masuk dengan akun.

Langkah pertama

  1. Di editor Apps Script, pilih fungsi setupDatabase lalu tekan Jalankan, sekali. Spreadsheet dan data contohnya dibuat.
  2. Deploy → New deployment → Web app: Execute as Me, Who has access Anyone. Salin tautan /exec-nya.
  3. Buka tautan itu di HP, lalu Tambahkan ke layar utama agar tampil seperti aplikasi.
  4. Setelah mencoba, hapus data contoh lewat tombol "Hapus data contoh" (menu Pengaturan atau Bantuan).

Backup harian

Sekali saja: di editor Apps Script pilih fungsi aktifkanBackupHarian lalu tekan Jalankan dan izinkan. Setiap malam semua sheet disalin ke spreadsheet "gafi foya link — Backup", satu salinan per hari (Senin–Minggu), jadi 7 hari terakhir selalu ada. Untuk backup saat itu juga, jalankan backupSekarang.

Bantuan

Di aplikasi ada halaman Bantuan dan Tur singkat. Perubahan aplikasi (fitur baru, tampilan) dibuat lewat CodeStudio: buka aplikasinya di Aplikasi Saya lalu tulis perubahannya.
